9스펙 노트

확정 사항 ㉤ 출처 칩 — 행 40px · 폭 560px · 최대 8줄(356px) · 하단 바 34px. 출처는 오른쪽 끝 알약으로 세우고, 형제 앱만 --accent 색점, 스크립트는 --success, 앱·파일은 --text-muted. 종류별 머리글(㉣)은 쓰지 않는다 — 순위를 종류에 종속시켜 D-10·D-11을 동시에 깬다.
토큰 형제 앱 renderer/tokens.css를 그대로 쓴다. 이 앱이 더하는 토큰은 없다(PANEL-10). 패널 배경만 --ov-bg: rgba(22,23,28,.97) 로 두어 WHENMUSIC 카드(.96)와 같은 계열을 유지한다.
순위 규칙 목록 순서는 오직 base × (1 + log1p(hits) × recency) 가 정한다(D-10). 종류·출처·공급원 도착 순서 어느 것도 순서에 개입하지 않는다.
움직이지 않는 것 늦게 온 결과(D-11)는 목록 끝에 붙고, 이미 선택된 항목의 화면상 위치는 바뀌지 않는다. 진행 표시는 목록이 아니라 입력 행 오른쪽에 둔다.
빈 상태 빈 입력이면 frecency 상위 4줄(8줄 아님). 결과 0이면 스크립트 폴더로 안내한다 — 이 앱의 유일한 확장 지점이다.
형제 앱 0개 차이는 파란 칩 줄이 없다는 것뿐. 배너·권유·안내를 띄우지 않는다(D-03·LINK-01).
스크립트 출력 ≤3줄이면 자체 토스트(OS 알림 아님) 우상단 4초, 한 줄이면 자동 복사. >3줄이면 같은 패널이 아래로 자라 고정폭 출력. 실패는 이름표·상태·진행 표시가 전부 --danger, stderr 원문 + 경로:줄번호, ⌘↵로 스크립트 열기.
설정 별도 작은 창 540px(D-16). 섹션: 단축키 · 시작 · 스크립트 · 형제 앱 · 데이터 · 정보. 형제 앱 섹션은 네 상태(연결됨·설치 안 됨·매니페스트 오류·폴더 없음→섹션 숨김). 실패는 토글을 되돌리고 이유를 적는다.
트레이 아이콘은 ⌘ 한 글자(두 OS 동일). 첫 줄 "부르기", 형제 앱 줄은 읽기 전용. 항목 순서·글자는 두 OS 동일, 단축키 표기만 다름.
첫 실행 ① 트레이 안내 → ② 단축키 충돌(등록 실패 시에만, macOS) → ③ 첫 입력줄은 "자주 쓰는 것" 대신 사용법 힌트 한 줄(세 번 고르면 사라짐). 새 버전 카드는 입력줄 하단에 하루 한 번, macOS "받기" / Windows "지금 다시 시작".
측정으로 정할 것 1) 560px가 맞는 폭인지 — 긴 파일 경로가 잘리는 빈도를 2주 써 보고 정한다. 2) 행 40px에서 8줄이 실제로 한눈에 들어오는지, 6줄이 나은지. 3) backdrop-filter: blur(30px) 가 두 OS에서 같은 값으로 같아 보이는지 — WebView 렌더러가 다르다. 4) 하단 바가 필요한지 — 34px을 쓸 만큼 자주 읽히는지, 아니면 첫 실행 이후 죽은 픽셀인지. 5) 토스트 4초가 맞는지 — IP 주소 한 줄을 읽고 붙일 시간으로 충분한지. 6) 메뉴바에 when 아이콘 여섯이 나란히 있을 때 ⌘ 아이콘이 구분되는지 — 안 되면 형제 앱과 모양 규칙을 맞춰야 한다.
