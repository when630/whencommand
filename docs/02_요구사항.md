# WHENCOMMAND — 요구사항

> 프로젝트 정의는 [01_프로젝트.md](01_프로젝트.md), 기술 결정은 [03_기술_스펙.md](03_기술_스펙.md). ID 체계와 문서 형식은 WHENMUSIC `docs/02_요구사항.md`를 따른다. 2026-09-19 정의. 체크는 자동 테스트가 증명한 것만 — UI 항목은 실사용으로 확인한 뒤 체크한다. **POC로 가능성만 확인된 것은 체크하지 않고 본문에 실측 사실을 적는다.**

**Core Value:** 하려는 일을 적으면 된다. 그 일이 어느 앱에 있는지 기억하지 않는다.

## v1 Requirements

### 입력줄 (PANEL)

이 앱의 존재 이유다. 나머지 그룹은 전부 여기에 결과를 실어 보낸다.

- [x] **PANEL-01**: 전역 단축키로 입력줄이 뜬다. macOS `⌘Space`, Windows `Alt+Space` ([D-05](03_기술_스펙.md#d-05-단축키만은-os별로-다르게-둔다)). 설정에서 바꿀 수 있다
- [ ] **PANEL-02**: **눌러서 보이기까지 120ms 이내.** 창을 미리 만들어 숨겨 두고 보이기만 한다. 매번 새로 만들면 이 예산을 못 지킨다 ([D-06](03_기술_스펙.md#d-06-창은-미리-만들어-숨겨-둔다))
- [ ] **PANEL-03**: 입력줄은 기본으로 **화면 위 28% 중앙**에 뜬다. 커서가 있는 디스플레이 기준이다 (`whenwork/main/place.mjs` 승계, `centerY:false`). **마우스로 끌어 옮길 수 있고 그 자리를 기억한다** — 입력 행을 잡는다. 기억한 자리가 화면 밖이면(모니터를 뺐거나 해상도가 바뀌면) 기본 자리로 돌아오고, 트레이 메뉴 "입력줄 위치 되돌리기"로도 돌린다 ([D-19](03_기술_스펙.md#d-19-입력줄은-옮길-수-있고-자리를-기억한다-2026-09-21))
- [ ] **PANEL-04**: **전체화면 앱 위에** 뜬다. 전체화면 IDE·브라우저에서 가려지지 않는다
- [ ] **PANEL-05**: `Esc`·포커스 이탈·항목 실행 **셋 다**로 닫힌다. 닫힐 때 입력 내용이 비워진다
- [x] **PANEL-06**: 닫으면 **직전에 쓰던 창으로 포커스가 돌아온다.** 타이핑하던 자리에 커서가 그대로 있어야 한다 — 이걸 놓치면 앱을 부를 때마다 작업이 끊긴다
- [ ] **PANEL-07**: 다시 부르면 **항상 빈 줄**로 시작한다. 직전 입력을 남기지 않는다. `↑`로 직전 입력을 되부른다
- [ ] **PANEL-08**: 결과는 최대 **8줄**만 보인다. 그 아래는 스크롤한다. 첫 줄이 맞으면 스크롤할 일이 없어야 한다
- [x] **PANEL-09**: 마우스 없이 전부 조작된다. `↑`·`↓` 이동, `Enter` 실행, `⌘·Ctrl`+숫자로 직접 선택. 키 글자의 뜻은 형제 앱과 같다
- [ ] **PANEL-10**: 프레임 없는 창이고 디자인 토큰은 형제 앱 `renderer/tokens.css`를 그대로 쓴다. 이 앱이 더하는 토큰은 없다
- [ ] **PANEL-11**: 트레이 아이콘이 있고, 창을 닫아도 앱은 트레이에 남는다. 첫 실행 때 트레이 위치와 단축키를 안내한다 (형제 앱 `firstRunHint` 승계)

### 검색·랭킹 (SRCH)

- [x] **SRCH-01**: **초성으로 찾는다.** `ㅋㄹ`로 "크롬"이, `ㅁㅁ`로 "메모"가 나온다 (`whennote/main/search.mjs` 승계)
- [x] **SRCH-02**: **퍼지로 찾는다.** 연속하지 않아도 순서만 맞으면 걸린다 — `vsc`로 "Visual Studio Code"가 나온다
- [x] **SRCH-03**: 영문 앱 이름을 **한글 타자로 쳐도 걸린다.** `퍼갸ㅑㅔ`(chrome을 한글 자판으로 친 것)로 Chrome이 나온다. 자판 전환을 잊는 일이 잦기 때문이다
- [x] **SRCH-04**: **자주·최근에 고른 것이 위로 온다.** 점수는 빈도와 최근성을 함께 본다 ([D-10](03_기술_스펙.md#d-10-랭킹은-frecency다)). 같은 두 글자를 3회 이상 쳤으면 그 다음부터 원하는 것이 첫 줄이어야 한다
- [x] **SRCH-05**: 결과는 **종류가 섞여** 한 목록에 온다 — 앱·파일·형제 앱 명령·스크립트·계산 결과. 종류별 탭을 두지 않는다
- [x] **SRCH-06**: 각 줄에 **어디서 온 것인지**가 아이콘과 꼬리표로 드러난다. 같은 이름의 앱과 파일이 나란히 왔을 때 구분돼야 한다
- [ ] **SRCH-07**: 입력이 비어 있으면 **입력줄만** 보인다 — 목록도, 사용법 안내도 미리 채우지 않는다 ([D-18](03_기술_스펙.md#d-18-빈-입력은-입력줄만이다-2026-09-21)). 사용법은 트레이의 첫 실행 안내(PANEL-11)가 맡는다
- [x] **SRCH-08**: 검색은 **타이핑을 막지 않는다.** 결과 계산이 늦어도 글자는 즉시 들어간다. 느린 공급원(파일 검색)은 늦게 도착해 목록에 합류한다 ([D-11](03_기술_스펙.md#d-11-공급원은-비동기로-합류한다))

### 앱 실행 (LNCH)

- [ ] **LNCH-01**: 설치된 앱을 찾아 `Enter`로 연다. 이미 떠 있으면 **새로 띄우지 않고 그 창으로 간다**
- [ ] **LNCH-02**: macOS는 `/Applications`·`/System/Applications`·`~/Applications`의 `.app`을 모은다. 앱 이름은 `CFBundleDisplayName` 우선, 없으면 `CFBundleName`
- [ ] **LNCH-03**: Windows는 시작 메뉴(`%ProgramData%`·`%APPDATA%`)의 `.lnk`와 **UWP 앱**(`shell:AppsFolder`)을 모은다. 둘 중 하나만 보면 목록이 반쪽이 된다
- [ ] **LNCH-04**: 앱 아이콘을 뽑아 목록에 보여 준다. 뽑기 실패는 기본 아이콘으로 넘어가고 앱을 멈추지 않는다
- [ ] **LNCH-05**: 앱 목록은 **시작할 때 한 번 모으고 캐시**한다. 새로 설치한 앱은 트레이 메뉴의 "목록 새로고침"이나 다음 실행에 반영된다. 매 검색마다 디스크를 훑지 않는다

### 파일 열기 (FILE)

- [x] **FILE-01**: 파일을 이름으로 찾아 기본 앱으로 연다. **OS 인덱스에 위임**한다 — macOS `mdfind`, Windows Search ([D-09](03_기술_스펙.md#d-09-파일-검색은-os-인덱스에-위임한다))
- [x] **FILE-02**: 파일 결과는 **경로가 함께** 보인다. 같은 이름의 파일이 여럿일 때 구분돼야 한다
- [x] **FILE-03**: 파일 검색은 **입력 3글자부터** 돈다. 한두 글자로 전체 디스크를 훑으면 결과가 쓸모없고 느리다
- [x] **FILE-04**: 폴더는 파일 탐색기로 연다. `⌘·Ctrl+Enter`는 파일이 든 폴더를 연다
- [ ] **FILE-05**: OS 인덱스를 못 쓰는 상태(macOS Spotlight 비활성 등)면 **그 사실을 한 줄로 알린다.** 조용히 결과 0으로 두지 않는다

### 계산·변환 (CALC)

- [x] **CALC-01**: 입력이 수식이면 **첫 줄에 답**이 뜬다. `1920*0.28` 같은 것이 즉시 계산된다
- [ ] **CALC-02**: `Enter`로 결과를 클립보드에 복사하고 창을 닫는다
- [x] **CALC-03**: 단위 변환을 한다 — 길이·무게·온도·데이터 크기. `3.5kg to lb` 형태
- [x] **CALC-04**: 수식이 아닌 입력을 수식으로 오인하지 않는다. 계산 결과 줄이 앱 검색을 밀어내면 안 된다

### 스크립트 명령 (EXT)

- [x] **EXT-01**: 지정 폴더(`~/.whencommand/scripts/`)의 실행 가능한 스크립트가 **명령으로 목록에 뜬다** ([D-07](03_기술_스펙.md#d-07-확장은-셸-스크립트다))
- [x] **EXT-02**: 스크립트 상단 주석으로 **이름·설명·아이콘**을 선언한다. 선언이 없으면 파일명을 이름으로 쓴다
- [x] **EXT-03**: 스크립트는 `sh`(macOS)·`powershell`(Windows)로 실행된다. 확장자로 실행기를 정한다
- [x] **EXT-04**: 스크립트 출력을 보여 준다. **3줄 이하는 자체 토스트**(우상단 4초, 한 줄이면 클립보드에 자동 복사), **그 밖은 같은 패널이 아래로 자라** 고정폭으로 보인다 ([D-17](03_기술_스펙.md#d-17-스크립트-출력은-길이로-가른다-2026-09-19)). 새 창을 띄우지 않는다
- [x] **EXT-05**: 스크립트가 실패하면(0이 아닌 종료 코드) **stderr를 보여 준다.** 조용히 실패하지 않는다
- [x] **EXT-06**: 스크립트 폴더는 트레이 메뉴에서 연다. 폴더가 없으면 첫 실행 때 예제 하나와 함께 만든다

### 형제 앱 연동 (LINK)

**이 그룹은 전부 선택적이다.** 형제 앱이 하나도 없어도 v1은 완성이다 ([D-03](03_기술_스펙.md#d-03-형제-앱이-하나도-없어도-온전히-동작한다)).

- [x] **LINK-01**: `~/.when/apps/*.json` 매니페스트를 읽어 형제 앱의 명령을 목록에 합친다. **폴더가 없으면 조용히 넘어간다** — 오류도 안내도 띄우지 않는다
- [x] **LINK-02**: 매니페스트는 형제 앱이 **설치·실행 시 스스로 떨어뜨린다.** WHENCOMMAND가 형제 앱을 찾아다니지 않는다 ([D-04](03_기술_스펙.md#d-04-연동은-파일-기반-수동적-발견이다))
- [x] **LINK-03**: 명령 실행은 **딥링크**(`whennote://new?title=...`)로 한다. 앱이 꺼져 있으면 OS가 실행해 준다
- [x] **LINK-04**: 매니페스트에 적힌 앱이 **실제로 설치돼 있는지 확인**하고, 없으면 그 명령을 목록에서 뺀다. 지운 앱의 매니페스트가 남아 있을 수 있다
- [x] **LINK-05**: 매니페스트 형식이 깨졌으면 **그 파일만 건너뛴다.** 한 앱의 잘못된 파일이 전체 목록을 죽이면 안 된다
- [x] **LINK-06**: 규약은 별도 저장소 `when-protocol`에 둔다. 스키마와 예제가 거기 있고, 형제 앱은 그걸 보고 매니페스트를 만든다 ([D-12](03_기술_스펙.md#d-12-규약은-별도-저장소에-둔다))

### 플랫폼 (PLAT)

- [x] **PLAT-01**: OS 분기는 `main/platform/` 안에만 있다. 다른 파일이 `process.platform`을 직접 보지 않는다 (형제 앱 `PLAT-06` 승계). `test/platform.test.mjs`가 두 구현의 모양이 같은지 계약으로 검사한다
- [x] **PLAT-02**: 단축키를 설정에서 바꾼다. **등록 실패가 화면에 드러난다** — macOS `globalShortcut.register()`가 참을 돌려주고도 실제로는 안 눌리는 경우가 보고돼 있다 ([03 §12 실측 로그](03_기술_스펙.md#12-실측-로그))
- [ ] **PLAT-03**: macOS `⌘Space`는 **Spotlight 기본값이다.** 첫 실행 때 Spotlight 단축키를 끄거나 바꾸는 방법을 안내한다. 안내 없이는 앱이 고장 난 것으로 읽힌다. **(2026-09-19 실측)** Spotlight가 켜져 있으면 `⌘Space`에 **둘이 동시에 뜬다** — 앱이 막을 수 없다. `defaults read com.apple.symbolichotkeys`의 64번 `enabled`를 읽어 켜져 있을 때만 안내한다
- [x] **PLAT-04**: Windows `Alt+Space`는 **창 시스템 메뉴 기본값이다.** 가로채지는지 실측하고, 안 되면 대안 조합으로 내려간다 ([03 §12](03_기술_스펙.md#12-실측-로그))
- [x] **PLAT-05**: 로그인 시 자동 실행을 켜고 끈다. **돌려받은 값으로 실제 적용을 확인**한다 — 미서명 앱에서 조용히 실패한다
- [ ] **PLAT-06**: macOS는 Dock 아이콘을 뺀다. Windows는 `AppUserModelId`를 설정해 알림에 앱 이름이 제대로 붙게 한다
- [x] **PLAT-07**: 첫 실행 안내가 OS별로 다르다 — macOS는 메뉴바, Windows는 트레이 숨김 영역(`^`)

### 저장소 (STOR)

- [ ] **STOR-01**: `node:sqlite` 단일 파일에 저장한다. 외부 의존성을 더하지 않는다 (형제 앱 동일)
- [ ] **STOR-02**: 저장하는 것은 **랭킹 데이터뿐**이다 — 무엇을 언제 몇 번 골랐는지. 검색어 원문은 남기지 않는다
- [x] **STOR-03**: 저장소를 지워도 앱은 정상 동작한다. 랭킹만 처음 상태로 돌아간다
- [x] **STOR-04**: 설정을 JSON으로 내보내고 가져온다. 랭킹은 기기마다 다른 데이터라 담지 않는다

### 릴리스 (REL)

- [x] **REL-01**: **두 OS 모두** 설치 파일을 낸다 — Windows NSIS, macOS DMG. 한쪽이 부록이 아니다
- [x] **REL-02**: GitHub Releases 미서명 배포 + `electron-updater`. Windows는 자동 설치, **macOS는 알림까지만** — Squirrel.Mac이 서명을 요구한다 (형제 앱 `canAutoUpdate` 승계)
- [x] **REL-03**: `test/`가 CI에서 돈다. 순수 함수(검색·랭킹·창 배치·매니페스트 파싱)는 Electron 없이 검증된다
- [x] **REL-04**: README에 두 OS의 설치법과 **각 OS의 단축키 충돌 해결법**이 적혀 있다

### 완료 판정 (DONE)

- [ ] **DONE-02**: 형제 앱 단축키를 떠올리려다 멈칫한 횟수가 0에 가깝다
- [ ] **DONE-03**: "이건 이쪽 OS에선 안 되지"라고 생각한 적이 0회다
